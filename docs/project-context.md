# Project context and attribution

This repository describes a fictional customer-churn scenario used for the Nackademin MLOps25 course exercise. Saldes Mobil AB and the customer records are fictional, as stated in the repository README.

## Scope

The assignment focuses on CI workflows, tests and configuration for reliable model delivery. The README explicitly reserves model and feature implementation in `src/churn/data.py` for the analyst team.

## Safe portfolio description

Describe this repository as coursework or a team exercise unless your individual contribution is independently documented. When presenting individual work, link to the exact pull requests or commits that demonstrate it.

## Delivery principle

A model should only become a customer-facing artifact after automated tests and model-quality checks pass, and its source commit and data lineage should be traceable.
